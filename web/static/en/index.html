FAQ

The short version

Will my chat partner see my Telegram?

No. Your username, contact and profile photo stay hidden until both sides agree to reveal them.

Can I use it without Premium?

Yes. Search and text chat are free. Premium unlocks extra features, including calls.

How do I switch to a new chat partner?

End the current conversation and start a new search with the same or new settings.

What if someone breaks the rules?

End the conversation, send a report, and block the user if needed.
