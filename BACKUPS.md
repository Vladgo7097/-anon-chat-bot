# Резервные копии

База анонимного бота копируется ежедневно в `03:15 UTC` системным таймером
`anon-chat-backup.timer`. Файлы находятся на сервере в
`/opt/anon-chat-backups`, доступны только `root` и хранятся 14 дней.

Каждая новая копия сначала проверяется командой `pg_restore --list`, затем
полностью восстанавливается во временную базу `anon_chat_backup_verify` и
проверяется чтением таблицы пользователей. Только после этого файл получает
окончательное имя. Временная база всегда удаляется. При ошибке сервис ставит
владельцу одно служебное уведомление через штатную очередь бота.

Проверка состояния:

```sh
systemctl status anon-chat-backup.timer
systemctl status anon-chat-backup.service
ls -lh /opt/anon-chat-backups
```

Проверка восстановления должна выполняться в отдельной тестовой базе. Нельзя
направлять `pg_restore` в рабочую базу `anon_chat`.
